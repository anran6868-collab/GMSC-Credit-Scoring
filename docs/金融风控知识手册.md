# 金融风控知识手册

本手册解释 GMSC 教学项目的建模、评分和评价口径。目标变量 `SeriousDlqin2yrs=1` 表示未来两年严重逾期；模型输出是概率估计，不代表真实授信审批结论。

## 一 数据边界与泄露防护

有标签样本按目标变量分层随机划分为训练集 70%、验证集 15%、测试集 15%。缺失和异常规则、特征筛选、分箱、WOE/IV 与模型参数只在训练集拟合。验证集用于冻结模型选择；测试集在三模型和阈值冻结后只评价一次。无标签的 Kaggle 测试文件不等于本项目的评价测试集。

同一个变量的缺失率、坏率、IV 与 PSI 可以用于不同问题：缺失率描述数据质量；坏率描述观察到的群体差异；IV 衡量训练集单变量区分；PSI 衡量两个样本的分布变化。它们都不能单独证明因果，也不能代替模型的概率校准检查。

## 二 特征、分箱、WOE 与 IV

项目保留原始变量，构造可解释的业务衍生变量，如历史逾期总次数、严重逾期标记、估算月债务与人均剩余收入。第三阶段共有 20 个非 WOE 候选特征；最终 Logistic 评分卡选择 8 个变量。衍生变量的定义和入模状态见综合 Excel 的“特征定义”“特征筛选”表。

专业分箱将连续变量划为风险相对稳定的区间。每箱应检查样本量、坏客户数、特殊值、坏率趋势和无限 WOE。WOE 是箱内好坏占比相对总体好坏占比的对数比；本项目以已验收的 OptimalBinning 输出及评分卡规则为准，不手工改变符号。IV 是各箱好坏占比差异与 WOE 贡献的汇总。高 IV 变量仍要检查目标泄露、变量重复、相关性和业务合理性。

PSI 比较训练集和验证集的分箱占比，不使用验证集标签。PSI 小只说明该划分下分布相近，不能保证模型有效或公平。

## 三 Logistic 概率与信用分

Logistic 模型先由 WOE 变量计算坏客户 logit，再以 `PD = 1 / (1 + exp(-logit))` 转成严重逾期概率。项目评分参数为基准分 600、好坏 Odds 20:1、PDO 20。以 `F = 20 / ln(2)` 表示分数因子，信用分满足：

`Score = 600 + F × ln(((1 - PD) / PD) / 20)`。

因此 PD 越高，分数越低。变量积分贡献与基础分之和等于未取整总分；展示信用分是该总分四舍五入后的整数。A–E 风险等级边界来自训练集评分分位数，未用验证或测试集重新调节。模型分类阈值与信用分 Cut-off 是不同用途的量，不应混用。

## 四 评价指标如何读

- AUC 衡量随机抽取一名坏客户和一名好客户时，模型把坏客户排在更高风险位置的概率；它不直接衡量 PD 是否准确。
- KS 是坏客户和好客户累计分布差的最大值，关注风险排序分离。
- PR-AUC 描述 Precision–Recall 曲线，类别不平衡时尤其需要与基线坏率一起解读。
- Precision 是预测为坏的样本中实际坏的比例；Recall 是全部坏客户中被识别的比例；F1 是两者的调和平均。三者依赖固定阈值。
- Brier 是概率与实际二分类标签的均方误差；Log Loss 对自信但错误的概率惩罚更强。校准截距、斜率与校准曲线用于检查概率可靠性。

项目不是只凭 AUC 选择模型。验证集综合比较后，XGBoost 是最佳树模型挑战者；Logistic 保持主评分卡路线。测试集审计只用于报告泛化表现，不反向改变模型或阈值。

## 五 模型解释

Logistic 的 WOE、系数和积分贡献解释主评分卡的每一项分值。RF 和 XGBoost 的 SHAP 在严重逾期概率空间计算；基准值与变量贡献应加总回该模型的 PD。全局 SHAP 描述已选解释样本上的平均影响，局部 SHAP 描述固定代表客户。SHAP 是模型解释，不是变量对逾期的因果效应。

## 六 风险策略与应用限制

最低通过分越高，通常通过人数越少，但具体通过率、通过客户坏率和被拒坏客户捕获率必须从指定样本计算。本项目策略页和第八本 Notebook 使用训练集真实评分与标签，是样本内教学模拟，结果可能偏乐观。无人通过时，通过客户坏率不可计算。

公开竞赛数据缺少真实授信规则、时间外样本、审批成本、收益、损失金额和上线监控环境。部署本地八页面系统只是成果展示；任何真实业务使用都需要独立的数据、合规、校准、稳定性和公平性评估。
